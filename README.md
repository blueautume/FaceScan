# FaceScan

原生 iOS 本地面部扫描工具。使用前置 TrueDepth 的真实深度与颜色，在扫描过程中逐步生成彩色点云，重复观测覆盖已有区域，点云随头部旋转和平移。准备、扫描、结果查看与隐私操作都在同一界面完成；导出通过系统文件面板由用户选择保存位置。也可作为 PLY 查看器，从系统「文件」打开模型，在原界面旋转、缩放查看。

最低 iOS 17，无第三方 SDK、账号、网络请求或云端后端。真实扫描需要配备前置 TrueDepth 的 iPhone；普通设备与模拟器可查看 PLY 文件。查看文件不会请求或启用相机。

应用显示名称、工程、主 Target 与 Scheme 均为 `FaceScan`。主应用 Bundle ID 为 `top.furby.FaceScan`，测试 Target 为 `FaceScanTests`，测试 Bundle ID 为 `top.furby.FaceScanTests`。

## 使用

1. 用 Xcode 打开 `FaceScan.xcodeproj`，保留当前项目结构，在 Signing & Capabilities 选择自己的开发团队，连接 iPhone 运行。
2. 首次启动先阅读并同意界面中的隐私协议，相机权限仅在点击「开始扫描」时请求；不同意协议时不会启用相机，仍可打开本地 PLY。
3. 手机距脸约 30–50 厘米，正对镜头，点击「开始扫描」。保持自然表情，缓慢向两侧转头，再轻轻低头和抬头。底部七段细线表示不同视角的观测覆盖，一次只显示当前动作提示。
4. 点云实时形成，右上角保留取景小窗。已采区域保留；重访同一区域时，最新有效深度帧覆盖该点的位置与颜色。扫描期间由头部姿态控制展示，停止后恢复拖动旋转、双指缩放。
5. 点击「停止扫描」，在原位置查看完整稳定点云，再点击「导出 PLY」，在系统面板选择文件夹、文件名与保存位置；保存成功后原界面显示「已导出」，取消不会自动保存到 Documents。未扫到的区域保留缺口；有效点不足时会停止本轮并提示重扫。没有定时自动停止。
6. 顶部手掌图标可随时查看协议或撤回同意。撤回会停止采集、取消正在进行的导出、清除当前扫描与 App 的临时导出。已自行保存的文件由用户管理。

## 滤波测试分支

`codex/filter-test` 在扫描结束后提供「滤波」按钮。点击后在后台处理完整扫描快照；处理期间可取消，完成后自动显示滤波点云，可通过「原始 / 滤波后」切换对比，旋转与缩放位置保持一致。界面显示处理前后点数和算法耗时，原始扫描仍保留在内存。重新扫描、撤回同意会取消处理并清空滤波副本；打开 PLY 会取消正在进行的滤波，已有结果保留，关闭文件可继续对比。

核心 `FacePointCloudProcessor.swift` 基于用户提供的 `FacePointCloud_iOS_Reference.zip`，增加了可选的起伏曲线控制；关闭曲线时沿用原参考处理路径。原有 20 邻点 / 2.5σ SOR、1.5 mm 网格、5×5 中值、3 次双边滤波和颜色去噪保留为「参考参数」预设。输入沿用项目已有的 ARFaceAnchor 局部米制坐标，RGB 在适配层转换为 8 位颜色；没有额外坐标变换。仅处理已完成的扫描，不处理实时帧或任意导入的 PLY。

扫描结果页的「滤波参数」开放 18 个基础算法参数和可选的平滑强度曲线，按几何平滑、删点门限、颜色和高级柱面坐标分组，长度以毫米显示。首次默认使用「轻度」预设：0.75 mm 网格、关闭空间中值、1 次双边滤波、半径差 σ 为 2 mm、SOR 标准差倍数 3.5、关闭颜色去噪。可一键恢复参考参数或自行调整；参数偏好保存在本机，下次启动继续使用。

可调参数版已保留在提交 `8f851e9`。其后的曲线功能在「滤波参数 → 平滑强度曲线」启用：横轴是局部起伏（mm），纵轴是实际几何平滑强度（0–100%）。五个控制点可上下拖动，也可轻点图内设置最近控制点，选中后可用滑块按 1% 调整；点之间使用平滑、有界的非线性插值。提供「保留起伏」「统一平滑」「不移动」曲线预设，可调起伏范围和评估半径。轻度与参考预设默认关闭曲线，旧版保存的参数也保持曲线关闭。

曲线的起伏指标从原始观测格计算：在评估半径内去掉局部倾斜后计算径向残差 RMS，并考虑来源点与本格中位半径的差异，减少同格不同层次被提前融合的问题。该指标不会识别皮肤或五官，较大的噪声同样可能得到保护。非统一曲线在观测不足的边界保留原位置；统一强度曲线可显式控制所有 SOR 保留点。

最终位置按「原始位置 + 曲线强度 ×（完整滤波位置 − 原始位置）」混合，覆盖网格融合、中值与双边滤波产生的几何位移。0% 精确保留来源坐标，100% 沿用完整滤波结果；最大径向位移剔除在混合之后检查。SOR 离群剔除和颜色去噪独立生效，使用「不移动」曲线并不关闭这两项。每次从原始扫描重算，曲线也参与参数缓存、偏好保存和 PLY 参数记录。

调整不会立即计算，点「应用并滤波」或结果页「重新滤波」才生效。每次均从原始扫描重算，不对上一次滤波结果叠加处理；计算期间以及失败、取消后保留上一次成功结果。结果页显示离群剔除和位移超限剔除的点数，参数尚未应用时会提示。要减轻平滑，可缩小网格间距、减少双边次数和半径差 σ；提高 SOR 标准差倍数可减少离群剔除。最大径向位移门限调小会删除更多点，不等于减轻平滑。

滤波会改变坐标、颜色和点数，结果用于观感预览；不能恢复缺失的五官细节，也不能视为原始测量值。滤波输出只有点云，清空原三角面，不重新生成网格。「导出 PLY」保存当前选择的版本，处理版文件名带 `-filtered-`，文件注释标明实际颜色策略，并以米制 JSON 记录已应用的全部参数；切回「原始」可导出原始扫描。滤波仍完全在本机执行。

模拟器可使用 Debug 启动参数 `--sample` 检查按钮、处理和切换效果，示例始终标注为合成数据。压缩包验证报告中的四份真实扫描未包含在项目或压缩包中，因此不能在这里重现该报告；真实扫描效果和 iPhone 耗时仍需用 TrueDepth 设备验收。

## 呈现增强与点大小

扫描过程中和完成页均提供点大小滑块，范围 `0.25×–4×`，可恢复 `1×`；点击倍数可快速选择常用预设。扫描与结果的大小分别记住；调整只更新已有点元素的渲染尺寸，不重新整理顶点、不改变视角或头部姿态。点大小用于点云模式；原色模式下若显示原始三角面，主界面滑块会停用。

完成后打开「呈现增强」，可对当前选中的原始或滤波点云生成显示副本。全表面按局部原始点距进一步细分，原本密集的区域也参与加密。开关可立即对比，修改参数后点击「应用并增强」重新计算。新点从有观测支持的局部表面采样，固定随机种子并缓存结果，旋转时不会重新随机；原有点的位置与颜色精确保留。处理在后台进行，可以取消；重新扫描、打开文件或撤回同意会取消正在进行的处理，撤回同意也会清空显示副本。切换原始/滤波结果时分别缓存最多两份显示结果。

| 参数 | 默认值 | 作用 |
| --- | --- | --- |
| 表面采样倍率 | 4× | 提供 1×/2×/4×/8×/16×；以局部原始间距继续细分，4×约使点距减半，已密集区域也增加采样 |
| 目标点间距 | 0.8 mm | 与「原始局部典型间距 ÷ √倍率」取更细者，作为该处新增点的最小距离约束；不移动原有点 |
| 局部拟合半径 | 4 mm | 用于邻域表面与方向估计，观测不足或拟合不可靠时跳过 |
| 允许补点跨度 | 3 mm | 限制支持三角形各边长度，避免跨越较大的空隙或向外延伸 |
| 几何边缘保护 | 70% | 越高，局部残差、法线转折和分层附近的补点越保守 |
| 颜色差异容许值 | 60 | 按每通道 0–255 的 RGB 向量差筛选同一局部颜色区域，较小值减少跨颜色边界插值 |
| 显示点数上限 | 20 万 | 可选 10/20/30/40 万；限制新增点造成的增长，来源点多于上限时全部保留且不再新增 |

增强仅作用于显示缓冲，不覆盖原始或滤波数据；常规「导出 PLY」仍保存当前选择的原始或滤波版本，不包含显示插值点。提高的是表面采样分辨率，不能恢复未采到的几何。倍率是单位面积点数的目标比例，实际输出受已有点分布、边界保护、数量及计算预算约束，不保证点数恰好成倍。当前实现使用局部 PCA 表面拟合、邻域法线/残差/颜色约束、短边支持区域采样和局部最小点距检查；不向自由三维空间添加随机扰动。有限预算按分散的表面顺序分轮采样，避免只加密输入顺序靠前的区域。小于保护阈值的真实缝隙与采样空隙仍可能难以区分，应通过开关比较五官边缘，并按真实扫描调整参数。旧版保存的参数保持原值，新倍率自动采用 4×。

首版验证（2026-10-26）：模拟器执行 216 项测试，215 项通过、1 项 TrueDepth 真机测试跳过，iOS Release 编译通过。覆盖局部表面、最小间距、空洞与几何/颜色边界、随机确定性、点数预算、取消与迟到结果、显示缓存归属、独立点大小偏好、尺寸变化不重建顶点或重置视角。原版未提供全表面倍率，合成样例 17,221 → 35,244 点；Mac 优化构建约 0.88 秒，Debug 约 13.23 秒，不代表 iPhone 性能。实际操作了实时合成演示的大小预设、结果增强及开关，真实扫描观感仍需真机比较。

## PLY 查看器

- 安装或更新应用后，系统可将 FaceScan 用于打开 `.ply` 文件。在「文件」中点击 PLY；若已有其他默认查看器，可在系统提供的打开方式中选择本应用。
- 也可点击界面顶部的文件夹图标选择 PLY。文件在同一个主界面展示，点击「关闭文件」回到扫描。打开前已有的扫描结果会保留；正在扫描时先整理当前结果并暂停相机。
- 支持 PLY 1.0：ASCII、二进制小端、二进制大端；支持 XYZ、可选 RGB/alpha、额外标量与列表属性、普通多边形面。展示默认使用彩色点云，无颜色时使用浅灰色。
- 文件可使用米、毫米或其他坐标尺度。只对渲染缓存居中和缩放，原始坐标与源文件保持不变；查看时支持完整旋转和双指缩放。
- 文件通过安全作用域与 `NSFileCoordinator` 在后台只读加载，支持取消和连续切换文件。限额为 64 MB、50 万个顶点；损坏、截断、非法坐标、越界面索引或过于复杂的文件会显示错误。
- Info.plist 注册了系统 PLY 类型 `public.polygon-file-format` 和兼容导入类型 `top.furby.facescan.ply`，角色为 Viewer。SwiftUI `onOpenURL` 同时处理冷启动和已运行状态下的文件打开。

## 重建与展示

```text
ARSession / ARFaceTrackingConfiguration
  ├─ capturedImage：实际 RGB 颜色
  ├─ capturedDepthData：TrueDepth 实测深度
  └─ ARFaceAnchor：刚性头部姿态与宽松面部采集范围
      ↓ 深度反投影、校准、转换到人脸局部坐标（米）
      ↓ 2 mm 体素索引与跨格近邻关联
      ↓ 同帧像素均值，后续有效帧覆盖；至少两帧观测才确认
      ├─ 有界实时点云快照 → SceneKit 点渲染
      └─ 完整稳定点云与有效三角面 → 彩色 PLY
```

- 真实位置全部来自深度采样。ARKit 模板网格只提供姿态和范围，不作为扫描结果。
- 关联点保留稳定编号，后续帧直接替换 XYZ/RGB，不与历史帧继续求均值。同帧多个像素先求均值，避免像素顺序直接决定结果。旧帧和无效值不会覆盖数据。
- 覆盖依据当前视角实际更新的稳定点判断，不要求先生成三角面。无三角形的有效点云也可以完成与导出。
- 深度融合约 8 Hz；实时快照约每 0.25 秒更新，最多 24,000 点，抽样覆盖完整累计范围；最终查看与导出保留全部稳定点。
- 头部姿态以相机帧更新，通过锁保护的轻量存储供渲染器读取。30 Hz 姿态更新只改变点节点变换，不重建几何，也不触发 SwiftUI 每帧刷新。首帧标定平移起点，保留真实旋转。
- 从准备到扫描和结果始终保留同一个相机视图与点云视图，只调整尺寸和可见性，避免重新绑定运行中的 ARSession。用户停止时冻结当前展示姿态，结果更新保留相机位置。
- 追踪更换、相机中断或进入后台会重置未完成扫描，避免把不同人脸或不同坐标的观测混合。已完成模型保留在内存，重新扫描会替换。

## 导出与隐私

PLY 文件包含米制 XYZ、RGB 顶点颜色、有效三角面，以及采集帧数和视角覆盖注释。没有有效三角面时输出 `element face 0` 的标准点云文件，可用支持 PLY 的三维软件打开。

App 不录制原始相机画面，不进行身份识别，不保存扫描历史，不上传、不提供云同步，也不接入广告、分析或第三方追踪。只在本地 UserDefaults 记录同意的协议版本，以及滤波、呈现增强和点大小参数偏好；协议升版需要重新同意。`PrivacyInfo.xcprivacy` 声明无追踪、无数据收集，以及 UserDefaults 的应用自身偏好使用原因。

导出时由用户在系统文件面板决定保存位置，App 不自动将模型写入 Documents。应用内的扫描和查看保留同一个主界面，文件选择和保存使用系统浮层。

主动导出时才在 App 专用临时目录 `FaceScanExports` 生成以 `FaceScan-` 开头的 PLY 文件。完整写入后交给系统保存选择器；成功、取消或关闭后移除暂存文件，撤回同意会合作取消写入并清理部分文件，下次启动也会清理因进程中断遗留的临时导出和旧版暂存目录。已导出的文件由用户管理，撤回不会删除这些文件；用户若选择 iCloud 等文件提供商，由相应系统服务处理，App 自身没有上传接口。

## 范围
