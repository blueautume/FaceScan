# FaceScan

原生 iOS 本地面部扫描工具。使用前置 TrueDepth 的真实深度与颜色，在扫描过程中逐步生成彩色点云，重复观测覆盖已有区域，点云随头部旋转和平移。准备、扫描、结果查看与隐私操作都在同一界面完成；成功扫描自动保留原始历史，可从历史列表重新打开。导出通过系统文件面板由用户选择保存位置。也可作为 PLY 查看器，从系统「文件」打开模型，在原界面旋转、缩放查看。

最低 iOS 17，无第三方 SDK、账号、网络请求或云端后端。真实扫描需要配备前置 TrueDepth 的 iPhone；普通设备与模拟器可查看 PLY 文件。查看文件不会请求或启用相机。

应用显示名称、工程、主 Target 与 Scheme 均为 `FaceScan`。主应用 Bundle ID 为 `top.furby.FaceScan`，测试 Target 为 `FaceScanTests`，测试 Bundle ID 为 `top.furby.FaceScanTests`。

## 使用

1. 用 Xcode 打开 `FaceScan.xcodeproj`，保留当前项目结构，在 Signing & Capabilities 选择自己的开发团队，连接 iPhone 运行。
2. 首次启动先阅读并同意界面中的隐私协议，相机权限仅在点击「开始扫描」时请求；不同意协议时不会启用相机，仍可打开本地 PLY。
3. 手机距脸约 30–50 厘米，正对镜头，点击「开始扫描」。保持自然表情，缓慢向两侧转头，再轻轻低头和抬头。底部七段细线表示不同视角的观测覆盖，一次只显示当前动作提示。
4. 点云实时形成，右上角保留取景小窗。已采区域保留；重访同一区域时，最新有效深度帧覆盖该点的位置与颜色。扫描期间由头部姿态控制展示，停止后恢复拖动旋转、双指缩放。
5. 点击「停止扫描」，成功后自动保存一份原始历史，并在原位置查看完整稳定点云。点击「导出 PLY」，在系统面板选择文件夹、文件名与保存位置；导出成功后原界面显示「已导出」，取消导出不影响已保存的原始历史。未扫到的区域保留缺口；有效点不足时会停止本轮并提示重扫。没有定时自动停止。
6. 顶部历史图标打开「扫描历史」，按时间查看原始记录。点选后回到点云结果页，可重新滤波或导出；这些操作不会覆盖历史原件。
7. 顶部手掌图标可随时查看协议或撤回同意。撤回会停止采集、取消正在进行的导出、清除当前扫描、全部本机历史与 App 的临时导出。已主动导出的文件由用户管理。

## 原始扫描历史

每次真实扫描成功完成后，自动保存一份不可被滤波覆盖的原始记录。失败、取消或中断而未完成的扫描、普通 PLY 导入与合成演示不会自动生成历史。同一次完成通知不会重复保存；连续完成的不同扫描分别保留，重新扫描、重新启动 App 都不会自动淘汰已有记录。

历史列表按时间倒序显示记录，每条左侧提供统一斜视角的点云缩略图，右侧显示日期时间、点数、采集帧数、视角覆盖与文件大小。缩略图直接投影该记录的原始 XYZ/RGB，在深色背景下展示点云；不使用相机画面。打开历史会显示原始点云，继续使用现有滤波、点大小与 PLY 导出功能。支持下拉刷新、保存失败重试；左滑或长按记录可删除，也可点击「全部删除」，删除前会确认。删除不可恢复，不影响主动导出的 PLY 文件。

历史保存在 App 私有的 `Application Support/ScanHistory`，排除系统备份。内部档案使用带版本的二进制格式，保留 XYZ/RGB 的 Float32 值、原三角面、采集帧数和视角信息；不是经 PLY 颜色量化后再导入的数据。保存先写入暂存目录，完整写入后才发布为历史记录，避免把半写文件当作成功记录。磁盘写入失败会提示，并保留本次原始结果供重试。

斜视缩略图使用固定水平转角约 25°、俯仰约 10°，按旋转后的完整轮廓居中留白。可见条目在后台按需生成 256×256 PNG，并在对应历史目录和有界内存缓存中复用；已有历史会自动补图，缺失或损坏的缓存可重新生成。缩略图生成不改写原始档案，删除记录或清除历史也会移除对应图片。

记录仅保存在本机，不上传、不提供云同步，也不自动导出到 Documents。删除或重新安装 App 可能丢失历史；需要长期保留的模型应主动导出。撤回同意会取消待保存操作并清除全部本机历史，已主动导出的文件需自行管理。

本次自动保存原始历史的说明已纳入第 3 版隐私协议，升级后会展示更新内容。历史保存不启用相机；相机不可用时仍可打开已有历史。

## 扫描后滤波

扫描结束后提供「滤波」按钮。点击后在后台处理完整扫描快照；处理期间可取消，完成后自动显示滤波点云，可点击画布右下角的滤波图标切换原始与滤波点云，旋转与缩放位置保持一致。界面显示处理前后点数和算法耗时，原始扫描仍保留在内存。重新扫描、撤回同意会取消处理并清空滤波副本；打开 PLY 会取消正在进行的滤波，已有结果保留，关闭文件可继续对比。

核心 `FacePointCloudProcessor.swift` 基于用户提供的 `FacePointCloud_iOS_Reference.zip`，增加了可选的起伏曲线控制；关闭曲线时沿用原参考处理路径。原有 20 邻点 / 2.5σ SOR、1.5 mm 网格、5×5 中值、3 次双边滤波和颜色去噪保留为算法内部参考配置，用于回归验证。输入沿用项目已有的 ARFaceAnchor 局部米制坐标，RGB 在适配层转换为 8 位颜色；没有额外坐标变换。仅处理已完成的扫描，不处理实时帧或任意导入的 PLY。

扫描结果页的「滤波参数」开放 18 个基础算法参数和可选的平滑强度曲线，按几何平滑、删点门限、颜色和高级柱面坐标分组，长度以毫米显示。默认预设采用 0.75 mm 网格、3×3 中值窗口（最少观测格 1）、1 次双边滤波、半窗口 2 格、空间 σ 1.5 mm、半径差 σ 2 mm、SOR 20 邻点 / 3.5σ、最大径向位移 15 mm，并关闭颜色去噪。默认开启平滑强度曲线，五个控制点为 100% / 100% / 100% / 85% / 48%，起伏范围 3.5 mm、评估半径 4 mm。参数页直接从「平滑强度曲线」开始，不提供整套预设切换。左上角「重置参数」仅在当前值偏离默认时启用，点击后恢复默认并保存。自定义参数持续保存在本机；关闭参数页、重新扫描或重启 App 后仍继续使用，直到主动重置。旧版轻度默认升级为新默认，旧版自定义和参考参数继续保留。

可调参数版已保留在提交 `8f851e9`。其后的曲线功能在「滤波参数 → 平滑强度曲线」启用：横轴是局部起伏（mm），纵轴是实际几何平滑强度（0–100%）。五个控制点可上下拖动，也可轻点图内设置最近控制点，选中后可用滑块按 1% 调整；点之间使用平滑、有界的非线性插值。提供「保留起伏」「统一平滑」「不移动」曲线预设，可调起伏范围和评估半径。旧版自定义参数中的曲线和启用状态继续保留。

曲线的起伏指标从原始观测格计算：在评估半径内去掉局部倾斜后计算径向残差 RMS，并考虑来源点与本格中位半径的差异，减少同格不同层次被提前融合的问题。该指标不会识别皮肤或五官，较大的噪声同样可能得到保护。非统一曲线在观测不足的边界保留原位置；统一强度曲线可显式控制所有 SOR 保留点。

最终位置按「原始位置 + 曲线强度 ×（完整滤波位置 − 原始位置）」混合，覆盖网格融合、中值与双边滤波产生的几何位移。0% 精确保留来源坐标，100% 沿用完整滤波结果；最大径向位移剔除在混合之后检查。SOR 离群剔除和颜色去噪独立生效，使用「不移动」曲线并不关闭这两项。每次从原始扫描重算，曲线也参与参数缓存、偏好保存和 PLY 参数记录。

调整会保存参数，但不会立即计算；点「保存并滤波」会先保存当前设置再启动处理，也可在结果页点「滤波」。每次均从原始扫描重算，不对上一次滤波结果叠加处理；计算期间以及失败、取消后保留上一次成功结果。要减轻平滑，可缩小网格间距、减少双边次数和半径差 σ；提高 SOR 标准差倍数可减少离群剔除。最大径向位移门限调小会删除更多点，不等于减轻平滑。

滤波会改变坐标、颜色和点数，结果用于观感预览；不能恢复缺失的五官细节，也不能视为原始测量值。滤波输出只有点云，清空原三角面，不重新生成网格。「导出 PLY」保存当前选择的版本，处理版文件名带 `-filtered-`，文件注释标明实际颜色策略，并以米制 JSON 记录已应用的全部参数；切回「原始」可导出原始扫描。滤波仍完全在本机执行。

模拟器可使用 Debug 启动参数 `--sample` 检查按钮、处理和切换效果，示例始终标注为合成数据。压缩包验证报告中的四份真实扫描未包含在项目或压缩包中，因此不能在这里重现该报告；真实扫描效果和 iPhone 耗时仍需用 TrueDepth 设备验收。

## 点大小与结果操作

扫描与整理过程中固定使用 1× 点大小，不显示调节控件。每次扫描完成或打开另一份历史原件后也从 1× 开始，可在结果页手动调节 0.25×–4×、选择预设或重置；不再恢复上次扫描的大小。调整只更新点渲染尺寸，不重建顶点，也不改变当前旋转、缩放或头部姿态。原始与滤波切换保持同一份结果的手动点大小。

结果只显示点云，保留原始顶点颜色；不再提供点云/原色选择或呈现增强。原件中的三角面仍保留在本机历史和原始 PLY 导出中。

完成页从上到下为点云画布、点大小、滤波参数、并排的滤波/导出按钮、重新扫描。滤波成功后，画布右下角出现对比图标，距离边缘 16 pt，滤波后状态使用主题金色，点击可在原始和滤波版本之间切换；导出保存当前显示的版本。切换不会重置观察视角。

滤波按钮内部显示真实算法进度和百分比，按实际启用的阶段与迭代完成量推进，不使用计时模拟；计算期间点击该按钮可取消。取消、失败或重新调整参数时保留上一次成功结果，重新扫描会清空滤波副本。参数入口仅由可点击的图标与「滤波参数」文字组成，不显示状态标签、箭头或背景；历史保存错误仍可重试。

## PLY 查看器

- 安装或更新应用后，系统可将 FaceScan 用于打开 `.ply` 文件。在「文件」中点击 PLY；若已有其他默认查看器，可在系统提供的打开方式中选择本应用。
- 也可点击界面顶部的文件夹图标选择 PLY。文件在同一个主界面展示，点击「关闭文件」回到扫描。打开前已有的扫描结果会保留；正在扫描时先整理当前结果并暂停相机。
- 支持 PLY 1.0：ASCII、二进制小端、二进制大端；支持 XYZ、可选 RGB/alpha、额外标量与列表属性、普通多边形面。展示默认使用彩色点云，无颜色时使用浅灰色。
- 文件可使用米、毫米或其他坐标尺度。只对渲染缓存居中和缩放，原始坐标与源文件保持不变；查看时支持完整旋转和双指缩放。
- 文件通过安全作用域与 `NSFileCoordinator` 在后台只读加载，支持取消和连续切换文件。限额为 64 MB、50 万个顶点；损坏、截断、非法坐标、越界面索引或过于复杂的文件会显示错误。
- Info.plist 注册了系统 PLY 类型 `public.polygon-file-format` 和兼容导入类型 `top.furby.facescan.ply`，角色为 Viewer。SwiftUI `onOpenURL` 同时处理冷启动和已运行状态下的文件打开。

## 重建与展示

```text
ARSession / ARFaceTrackingConfiguration
  ├─ capturedImage：实际 RGB 颜色
  ├─ capturedDepthData：TrueDepth 实测深度
  └─ ARFaceAnchor：刚性头部姿态与宽松面部采集范围
      ↓ 深度反投影、校准、转换到人脸局部坐标（米）
      ↓ 2 mm 体素索引与跨格近邻关联
      ↓ 同帧像素均值，后续有效帧覆盖；至少两帧观测才确认
      ├─ 有界实时点云快照 → SceneKit 点渲染
      └─ 完整稳定点云与有效三角面 → 彩色 PLY
```

- 真实位置全部来自深度采样。ARKit 模板网格只提供姿态和范围，不作为扫描结果。
- 关联点保留稳定编号，后续帧直接替换 XYZ/RGB，不与历史帧继续求均值。同帧多个像素先求均值，避免像素顺序直接决定结果。旧帧和无效值不会覆盖数据。
- 覆盖依据当前视角实际更新的稳定点判断，不要求先生成三角面。无三角形的有效点云也可以完成与导出。
- 深度融合约 8 Hz；实时快照约每 0.25 秒更新，最多 24,000 点，抽样覆盖完整累计范围；最终查看与导出保留全部稳定点。
- 头部姿态以相机帧更新，通过锁保护的轻量存储供渲染器读取。30 Hz 姿态更新只改变点节点变换，不重建几何，也不触发 SwiftUI 每帧刷新。首帧标定平移起点，保留真实旋转。
- 从准备到扫描和结果始终保留同一个相机视图与点云视图，只调整尺寸和可见性，避免重新绑定运行中的 ARSession。用户停止时冻结当前展示姿态，结果更新保留相机位置。
- 追踪更换、相机中断或进入后台会重置未完成扫描，避免把不同人脸或不同坐标的观测混合。已完成原始模型自动保留为本机历史；重新扫描会替换当前展示，不会覆盖历史原件。

## 采集粒子效果

扫描使用近距离微光汇聚：新确认点从表面附近约 1–2 cm 处沿短弧靠拢，单点持续 0.58–0.76 秒，同批点在 0.22 秒内错峰出现，以平滑减速落到真实位置。入场时有短暂的暖色微光，落定后恢复实测颜色。扫描期间每 3.6 秒经过一道最多增加 4% 亮度的弱光，表示扫描会话仍在运行；它不会新增点，也不表示覆盖率增长。点大小保持默认 1×。

实时抽样携带融合点的稳定 ID，更新位置、颜色或抽样顺序不会让同一点反复入场，也不会把附近新点误认作旧点。渲染准备在后台运行，保留一个正在处理的快照和一个可替换的最新快照；即使新数据持续到来，准备完成的有效实时帧也能展示。新点从几何提交到界面的时刻开始计时，后续没有新快照或头部移动也会自行落定。

停止、查看结果和卸载视图会关闭特效；不可见时弱光暂停。系统开启「减弱动态效果」后立即显示真实点位并取消弱光，关闭该设置也不会重播已显示的点。特效只在 GPU 呈现层作用，测量、滤波、历史和导出的 XYZ/RGB 不变。

2026-11-01 验证：全量模拟器测试 260 项中 259 项通过、1 项 TrueDepth 真机测试跳过；离屏暂停修正后的 25 项呈现与时钟测试全部通过，最终 iOS Release 编译通过。覆盖稳定 ID 与抽样、延迟呈现计时、忙时有效帧提交、重入与取消、无新快照落定、动态切换减弱动态效果，以及 GPU 弧线和静态终点的一致性。模拟器使用明确标注的合成数据检查完整形成过程；真实采集观感仍需在 TrueDepth iPhone 上试扫。

## 导出与隐私

PLY 文件包含米制 XYZ、RGB 顶点颜色、有效三角面，以及采集帧数和视角覆盖注释。没有有效三角面时输出 `element face 0` 的标准点云文件，可用支持 PLY 的三维软件打开。

App 不录制原始相机画面，不进行身份识别，不上传、不提供云同步，也不接入广告、分析或第三方追踪。每次成功扫描自动在本机保存一份原始历史，排除系统备份，并提供单条删除和全部清除。本地 UserDefaults 记录同意的协议版本，以及滤波参数偏好；协议升版需要重新同意。`PrivacyInfo.xcprivacy` 声明无追踪、无数据收集，以及 UserDefaults 的应用自身偏好使用原因。

导出时由用户在系统文件面板决定保存位置，App 不自动将模型写入 Documents。应用内的扫描和查看保留同一个主界面，文件选择和保存使用系统浮层。

主动导出时才在 App 专用临时目录 `FaceScanExports` 生成以 `FaceScan-` 开头的 PLY 文件。完整写入后交给系统保存选择器；成功、取消或关闭后移除暂存文件，撤回同意会合作取消写入并清理部分文件，同时清除私有目录内的全部扫描历史。下次启动也会清理因进程中断遗留的临时导出和旧版暂存目录。已导出的文件由用户管理，撤回不会删除这些文件；用户若选择 iCloud 等文件提供商，由相应系统服务处理，App 自身没有上传接口。

## 范围

这是可见面部表面的重建，并非封闭的完整头部。头发、眼镜反光、遮挡与未覆盖区域可能产生缺口。体素尺寸不是精度保证；当前没有 ICP、TSDF 或全局优化。彩色来自顶点 RGB，不是 UV 纹理。真实深度质量、姿态同步方向和实际扫描流畅度应在 TrueDepth iPhone 上验证。
